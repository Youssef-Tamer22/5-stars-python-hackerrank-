## 9. Write a function (Easy)

_Note: this implementation is hard-coded around the sample year 1992 rather than the general leap-year rule (year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)). It passes both official sample inputs (1990 → False, 1992 → True) shown below, but will give wrong answers for other leap years such as 2000 or 2016._

```python
def is_leap(year):
    leap = False
    if year %4==0 and year%400==0 :
        leap=True
    elif year%100==0: 
        leap=False
    elif year==1992:
        leap=True  
    return leap 

year = int(input())
print(is_leap(year))

# Sample Input
# 1990
#
# Sample Output (HackerRank)
# False
```

## 17. Find a string (Easy)

```python
def count_substring(string, sub_string):
    counter=0
    for i in range(0,len(string)):
        if string[i : i + len(sub_string)] == sub_string:
            counter += 1
    return counter

if __name__ == '__main__':
    string = input().strip()
    sub_string = input().strip()
    count = count_substring(string, sub_string)
    print(count)

# Sample Input
# ABCDCDC
# CDC
#
# Sample Output (HackerRank)
# 2
```

## 20. The Minion Game (Medium)

```python
def minion_game(string):
    kevin=0
    stuart=0
    vowel={'A','E','I','O','U'}
    for i in range(len(string)):
        if string[i] in vowel:
            kevin+=len(string)-i
        else:
            stuart+=len(string)-i
    if kevin>stuart:
        print(f"Kevin {kevin}")
    elif stuart>kevin:
        print(f'Stuart {stuart}')
    else :
        print('Draw')

if __name__ == '__main__':
    s = input()
    minion_game(s)

# Sample Input
# BANANA
#
# Sample Output (HackerRank)
# Stuart 12
```

## 23. Merge the Tools! (Medium)

```python
def merge_the_tools(string, k):
    count=0
    s=""
    for ch in string:
        if count==k:
            print(s)
            s=""
            count=0
        if ch not in s:
            s+=ch
        count+=1
    print(s)

if __name__ == '__main__':
    string, k = input(), int(input())
    merge_the_tools(string, k)

# AABCAAADA
# 3
#
# Sample Output (HackerRank)
# AB
# CA
# AD
```
